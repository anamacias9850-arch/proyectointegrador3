# Café & Código — Tienda & Analytics Full-Stack

Aplicación web Full-Stack para gestión de inventario, registro de ventas y visualización de métricas en tiempo real.

## Tecnologías
- **Backend:** Python 3, FastAPI, Uvicorn, Pandas
- **Frontend:** HTML5, CSS3, JavaScript, Chart.js
- **Datos:** CSV (productos.csv, ventas.csv)

## Ejecución Local
1. Backend: `cd backend && uvicorn main:app --reload`
2. Frontend: Abrir `frontend/index.html` en el navegador.
